# Municipal Spending Pipeline

End-to-end data pipeline that turns South African National Treasury municipal finance data into a trusted star schema and Power BI report, so analysts can compare how metros spend their budgets without cleaning raw files by hand.

**Built with:** Microsoft Fabric | Python | SQL | Power BI

**Status:** In progress

## 1. Business Problem
Analysts comparing metro spending currently have to clean raw Treasury files by hand each time. This project delivers a clean, tested dataset and a report that supports comparing budget against actual spending across metropolitan municipalities.
